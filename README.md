## Each lab folder contains
- the `.java` source files (one public class per file, no packages)
- `README.md` with the run commands and point-form answers to the exercises
- `output.txt` with the real output of the programs

## How to run any lab
Requires JDK 17 or later (developed and tested on JDK 21).
```
cd lab01-classes-objects
javac *.java
java Car
```
Each lab folder is compiled on its own, so class names such as `Student` or `BankAccount` can repeat across labs without clashing.
